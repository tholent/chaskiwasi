# talon is NOT listed here — it's installed separately in the Dockerfile
# with --no-deps, because its own setup.py pulls in numpy/scipy/scikit-learn

# faust-cchardet stands in for the "cchardet" import talon.utils does
# unconditionally. The original PyPI "cchardet" package fails to build on
# Python 3.11+ (it pokes at a CPython internal header, longintrepr.h, that
# was removed) and is unmaintained upstream; faust-cchardet is the
# maintained fork the community moved to for exactly this reason, and ships
# prebuilt wheels so no compiler is needed in the runtime image either.
